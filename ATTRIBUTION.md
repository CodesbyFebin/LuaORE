# Attribution

LuaORE is the product name of this launcher, the Lumen Vale browser client, and this site.

The public catalog (games, mods, texture packs) lists packages written by their authors on ContentDB. This repository stores the catalog index, not a redistribution of every author zip. Each package keeps its own license. Download a release from the ContentDB link on the package, then follow that license.
